How the value is computed

Implied value is this entry’s own claim, never make.fun’s: what a token would be worth if the protocol’s record stayed as it is. It does not predict whether or when a token is issued. “Records no token” means the DefiLlama record carries no market cap, CoinGecko id or symbol — a record, never proof a protocol has none, and this board does not predict whether or when it issues one. The peer rate counts what the peers’ record shows; the expected value is implied value weighted by that rate.
