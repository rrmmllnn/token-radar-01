How the value is computed

Implied value is this entry’s own claim, never make.fun’s: what a token would be worth if the protocol’s record stayed as it is. It does not predict whether or when a token is issued. “Records no token” means the DefiLlama record carries no market cap, CoinGecko id or symbol — a record, never proof a protocol has no token.
